# OMNI — управление версиями чертежей (из AutoCAD)

Набор AutoLISP-команд для создания и сравнения ревизий DWG прямо из AutoCAD.
Каждый «слепок» — полная копия текущего чертежа в папку `_OMNI_HISTORY`
рядом с файлом. Сравнение — наложение старой ревизии поверх текущей
(XREF + обесцвечивание), без выхода из AutoCAD.

## Установка

`APPLOAD` → `OMNI.lsp` → «Загрузить». (Файл в UTF-8, AutoCAD 2015+.)

## Команды

| Команда | Назначение |
|---|---|
| `OMNI-SNAP` | Слепок: сохраняет копию DWG в `_OMNI_HISTORY` с меткой времени, пользователем и описанием |
| `OMNI-LOG` | Список слепков; ввод номера — открыть нужную ревизию |
| `OMNI-DIFF` | Наложить выбранную ревизию как XREF (обесцвеченную) поверх текущего чертежа |
| `OMNI-CLEAR` | Снять наложение (удаляет только XREF-ы, созданные OMNI) |
| `OMNI-TOGGLE` | Показать/скрыть слои наложения (`<имя_xref>|*`) |
| `OMNI-NOTE` | Круглая заметка-комментарий на слое `OMNI_NOTES` |

## Именование слепков

```
_OMNI_HISTORY\<дата>-<время>_<мс>_<пользователь>_<описание>_<имя_файла>.dwg
```

Пример: `_OMNI_HISTORY\20260819.153012_482_kostyk_исправление_ПРОВОДКИ_PANEL.dwg`

## Что исправлено в v0.4

- `OMNI-TOGGLE` больше не ссылается на несуществующий слой `OMNI_DIFF_LAYER`:
  переключаются реальные слои XREF (`имя|*`).
- `OMNI-CLEAR` удаляет **только свои** XREF (имя содержит `_<имя_файла>`),
  чужие внешние ссылки не трогает.
- `OMNI-SNAP`: к имени добавлены миллисекунды — исключены коллизии при
  нескольких слепках в секунду; возвращает полный путь сохранённого файла.
- `OMNI-DIFF` корректно восстанавливает `FILEDIA`/`OSMODE`.
